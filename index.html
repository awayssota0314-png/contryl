변수 정리 & if문

값에 이름을 붙이는 변수를 짧게 정리하고, 조건에 따라 다른 일을 하는 if문을 배웁니다.

  • 변수와 =(대입)의 뜻을 설명할 수 있다.
  • 비교·논리 연산자로 조건을 만들 수 있다.
  • if · elif · else로 상황에 따라 다르게 동작하는 코드를 작성할 수 있다.

  • 콜론(:)을 치고 Enter → IDLE이 4칸 들여쓰기를 자동으로 해 줍니다.
  • else·elif처럼 앞으로 나와야 하는 줄은 Backspace로 들여쓰기를 지운 뒤 입력하세요.

개념 ①변수 한눈에 정리

지난 시간에 배운 내용을 짧게 되짚어 봅니다.

변수는 값에 붙이는 이름표입니다. 이름표를 붙여 두면 그 값을 이름으로 다시 꺼내 쓸 수 있어요.

>>> score = 80
>>> score
80
>>> score = score + 5
>>> score
85
이렇게 쓰면뜻
score = 8080이라는 값에 score라는 이름표를 붙인다 (=는 "같다"가 아니라 "넣는다")
score = score + 5지금 값(80)에 5를 더해서 다시 score에 넣는다 → 85
a, b = 3, 7여러 변수를 한 번에 만든다
a, b = b, a두 변수의 값을 맞바꾼다
>>> a, b = 3, 7
>>> a, b = b, a
>>> a
7
>>> b
3
변수 이름 규칙 — 영문자·숫자·밑줄(_)로 만들고, 숫자로 시작할 수 없어요. if, for 같은 예약어도 쓸 수 없고, 대문자와 소문자는 다른 이름이에요 (Score ≠ score).

개념 ②if문의 기본 구조

"비가 오면 우산을 챙기고, 아니면 모자를 쓴다"처럼 조건에 따라 할 일을 고르는 문장이 if문입니다.

if 조건문: 조건이 참일 때 할 일 1 조건이 참일 때 할 일 2 else: 조건이 거짓일 때 할 일
>>> rain = True
>>> if rain:
...     print("우산을 챙긴다")
... else:
...     print("모자를 쓴다")
... 
우산을 챙긴다
꼭 지켜야 할 3가지
① 조건 뒤, else 뒤에는 콜론(:)
② 조건에 딸린 문장은 들여쓰기 (공백 4칸)
③ 같은 블록의 문장은 들여쓰기 칸 수가 모두 같아야 해요
들여쓰기 칸 수가 들쭉날쭉하면 오류가 납니다.
>>> if rain:
...     print("우산을 챙긴다")
...       print("장화를 신는다")
IndentationError: unexpected indent

개념 ③조건 만들기 — 비교·논리·in 연산자

조건문의 결과는 언제나 True(참) 또는 False(거짓)입니다.

비교 연산자

연산자뜻예 (x = 5일 때)결과
x < yx가 y보다 작다x < 3False
x > yx가 y보다 크다x > 3True
x == yx와 y가 같다x == 5True
x != yx와 y가 같지 않다x != 5False
x >= yx가 y보다 크거나 같다x >= 5True
x <= yx가 y보다 작거나 같다x <= 4False
= 는 값을 넣는 것, == 는 같은지 비교하는 것! if x = 5: 처럼 쓰면 오류가 납니다.
>>> money = 2000
>>> money >= 3000
False
>>> if money >= 3000:
...     print("택시를 탄다")
... else:
...     print("걸어간다")
... 
걸어간다

논리 연산자 — 조건 여러 개 묶기

연산자뜻
x or y둘 중 하나라도 참이면 참
x and y둘 다 참이어야 참
not x참 ↔ 거짓을 뒤집는다
>>> money = 2000
>>> card = True
>>> if money >= 3000 or card:
...     print("택시를 탄다")
... else:
...     print("걸어간다")
... 
택시를 탄다

in · not in — 안에 들어 있는지 확인하기

리스트·튜플·문자열 안에 어떤 값이 있으면 in은 True, not in은 False가 됩니다. 할 일이 없으면 else는 생략해도 돼요.

>>> bag = ["필통", "교과서", "휴대폰"]
>>> "휴대폰" in bag
True
>>> if "휴대폰" in bag:
...     print("휴대폰은 수업 전에 제출하세요")
... 
휴대폰은 수업 전에 제출하세요

개념 ④elif — 여러 조건 중 하나 고르기

if 조건1: 조건1이 참일 때 elif 조건2: 조건1은 거짓이고 조건2가 참일 때 else: 모든 조건이 거짓일 때
>>> score = 83
>>> if score >= 90:
...     print("A")
... elif score >= 80:
...     print("B")
... elif score >= 70:
...     print("C")
... else:
...     print("D")
... 
B
위에서부터 차례로 검사해서 처음으로 참이 된 블록 하나만 실행하고 if문을 끝냅니다. 83은 70 이상이기도 하지만, 이미 score >= 80에서 걸렸기 때문에 "C"는 출력되지 않아요. 그래서 조건의 순서가 중요합니다. elif는 몇 개든 쓸 수 있어요.

개념 ⑤pass와 한 줄 if (조건부 표현식)

알아 두면 편리한 두 가지 문법입니다.

pass — 아무것도 하지 않기

조건이 참일 때 할 일이 없더라도 블록을 비워 둘 수는 없어요. 이럴 때 자리만 채우는 것이 pass입니다.

>>> pocket = ["지갑", "휴대폰"]
>>> if "휴대폰" in pocket:
...     pass
... else:
...     print("휴대폰을 챙기세요")
...

휴대폰이 있으니 아무것도 출력되지 않습니다.

조건부 표현식 — 한 줄로 값 고르기

변수 = 참일 때 값 if 조건 else 거짓일 때 값
>>> score = 55
>>> result = "통과" if score >= 60 else "재도전"
>>> result
'재도전'

3출력 결과 예상하기

실행하기 전에 먼저 예상해서 적고, 채점한 뒤 IDLE 셸에서 직접 확인해 보세요.

1. 출력 결과는?

>>> x = 7
>>> if x % 2 == 0:
...     print("짝수")
... else:
...     print("홀수")
...
정답 홀수 — 7을 2로 나눈 나머지는 1 → 조건이 거짓 → else 블록 실행.

2. 출력 결과는?

>>> age = 15
>>> ticket = False
>>> if age >= 14 and ticket:
...     print("입장 가능")
... else:
...     print("입장 불가")
...
정답 입장 불가 — and는 둘 다 참이어야 참. ticket이 False라서 전체가 거짓.

3. 출력 결과는?

>>> temp = 31
>>> if temp >= 30 or temp <= 0:
...     print("야외 수업 취소")
... else:
...     print("야외 수업 진행")
...
정답 야외 수업 취소 — or는 하나만 참이어도 참. 31 >= 30이 참.

4. 출력 결과는?

>>> n = 0
>>> if n > 0:
...     print("양수")
... elif n < 0:
...     print("음수")
... else:
...     print("영")
...
정답 영 — 0 > 0도, 0 < 0도 거짓 → else.

5. 출력 결과는?

>>> score = 95
>>> if score >= 70:
...     print("C 이상")
... elif score >= 90:
...     print("A")
... else:
...     print("노력 필요")
...
정답 C 이상 — 첫 조건 95 >= 70이 이미 참 → 아래 elif는 검사하지 않는다. 조건 순서 주의!

6. 출력 결과는?

>>> menu = ["김밥", "라면", "떡볶이"]
>>> if "우동" not in menu:
...     print("없는 메뉴입니다")
... else:
...     print("주문 완료")
...
정답 없는 메뉴입니다 — '우동'은 리스트에 없으므로 not in의 결과가 True.

4빈칸 채우기

코드 속 빈칸에 알맞은 연산자·기호·키워드를 쓰세요.

1. num이 짝수이면 "짝수"를 출력합니다.

>>> num = 10
>>> if num % 2  0:
...     print("짝수")
...
정답 == — 2로 나눈 나머지가 0과 '같은지' 비교 → ==

2. 오류가 나지 않도록 빠진 기호 하나를 채우세요.

>>> pw = "1234"
>>> if pw == "1234"
...     print("로그인 성공")
...
정답 : — 조건 끝에는 콜론(:)

3. 90점 이상이면 A, 그렇지 않고 80점 이상이면 B를 출력합니다.

>>> score = 85
>>> if score >= 90:
...     print("A")
...  score >= 80:
...     print("B")
...
정답 elif — 두 번째 조건은 elif

4. 키가 140cm 이상이고 나이가 10세 이상이면 "탑승 가능"을 출력합니다.

>>> height = 145
>>> age = 12
>>> if height >= 140  age >= 10:
...     print("탑승 가능")
...
정답 and — 두 조건을 모두 만족 → and

5. fruits 리스트에 "사과"가 들어 있으면 출력합니다.

>>> fruits = ["배", "사과", "귤"]
>>> if "사과"  fruits:
...     print("사과 있음")
...
정답 in — 리스트 안에 있는지 → in

while문 — 조건이 참인 동안 반복

같은 일을 여러 번 해야 할 때, 조건을 정해 두고 반복하는 while문을 배웁니다.

  • while문의 구조와 실행 흐름을 설명할 수 있다.
  • 반복의 세 요소(시작값 · 조건 · 변화)를 갖춘 반복문을 작성할 수 있다.
  • break와 continue로 반복의 흐름을 바꿀 수 있다.

  • else·elif처럼 앞으로 나와야 하는 줄은 Backspace로 들여쓰기를 지운 뒤 입력하세요.
  • 블록을 다 썼으면 빈 줄에서 Enter를 한 번 더 → 그때 실행됩니다.

개념 ①while문의 기본 구조

"줄넘기 5번"을 print로만 하면 다섯 줄을 써야 하지만, while문을 쓰면 몇 줄로 끝납니다.

while 조건문: 반복할 문장 1 반복할 문장 2

조건 검사 → 참이면 블록 실행 → 다시 조건 검사 → … 를 되풀이하다가, 조건이 거짓이 되는 순간 빠져나옵니다.

>>> count = 0
>>> while count < 5:
...     count = count + 1
...     print(f"줄넘기 {count}번")
... 
줄넘기 1번
줄넘기 2번
줄넘기 3번
줄넘기 4번
줄넘기 5번

실행 흐름 따라가기

회차조건 검사 (count < 5)count 값 변화출력
10 < 5 → True0 → 1줄넘기 1번
21 < 5 → True1 → 2줄넘기 2번
32 < 5 → True2 → 3줄넘기 3번
43 < 5 → True3 → 4줄넘기 4번
54 < 5 → True4 → 5줄넘기 5번
65 < 5 → False—반복 끝!

개념 ②반복의 세 요소와 무한 루프

반복문에는 세 가지가 꼭 필요해요.
① 시작값 count = 0   ② 조건 count < 5   ③ 변화 count = count + 1
③ 변화가 빠지면 조건이 영원히 참 → 무한 루프에 빠집니다! (Ctrl + C로 탈출)

줄여 쓰기

줄여 쓰기같은 뜻
n += 1n = n + 1
